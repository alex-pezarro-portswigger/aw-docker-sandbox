# aw-docker-sandbox

An [Agent Wrangler](https://github.com/PortSwigger/agent-wrangler) extension that adds a **Docker Sandbox** runtime. A dispatched card's agent (Claude Code or Codex) runs inside a local [Docker Sandboxes](https://docs.docker.com/ai/sandboxes/) (`sbx`) microVM instead of on the host.

Work in progress: nothing to install yet.
